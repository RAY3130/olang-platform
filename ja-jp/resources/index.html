よくあるご質問

確認できる範囲を明示した回答。

OLANGはメーカーですか、それとも商社ですか?

OLANG の公開会社概要には、仏山に拠点を置くバスルームハードウェアメーカーと記載されています。この Web サイトはその自己記述を複製し、企業報告としてマークを付けます。会社登録、工場監査書類、現在の生産証拠は、OLANG が確認した後にのみ入手可能です。

MOQとは何ですか?

これらの SKU については、検証済みの MOQ が公開されていません。 MOQは、購入リストがレビューされた後、製品、仕上げ、および注文の組み合わせごとに確認されます。問い合わせフォームでは目標数量を指定できるため、チームは一般的な数字ではなく具体的​​な回答を返すことができます。

サンプルをリクエストできますか?

サンプルの入手可能性、サンプルのコスト、宅配便の手配については公開されていません。製品、仕上げ、数量、目的地の詳細を送信します。チームはサンプルを提供できるかどうか、またどのような条件で提供できるかを確認します。

仕上げ、ロゴ、パッケージをカスタマイズできますか?

OLANG は、OEM/ODM およびプライベート ラベルのサポートについて公的に説明しています。この Web サイトは、すべての SKU またはプロセスがカスタマイズ可能であるとは主張しません。対象製品、変更、数量、市場を提出します。実現可能性、ツール、MOQ、タイミングは書面で確認されます。

製品は私の市場向けに認定されていますか?

包括的な認証は主張されません。 CE、UKCA、WaterMark、ADA、WRAS、REACH、またはその他の要件が特定の製品および市場に適用されます。すべてのステートメントは、正確な SKU をカバーする有効な文書によってサポートされている必要があります。文書リクエストを使用して、準拠範囲を尋ねます。

価格が表示されないのはなぜですか?

これらの製品は、仕様、数量、仕上げ、梱包、配送条件に基づいて見積もられます。検証済みの公開価格リストは利用できないため、テンプレート価格を表示すると誤解を招く可能性があります。購入リストを送信していただければ、チームが正確な構成を見積もります。

仕様書はどうやって入手できますか?

仕様シートは SKU ごとにリリースされ、企業によるレビューが必要になる場合があります。資料請求フォームに製品モデルと要求される資料を追加してください。パブリック ダウンロードは、実際のファイルがアップロードされ承認された場合にのみ表示されます。プレースホルダー PDF リンクは使用されません。

図面や機密ファイルをアップロードできますか?

はい、ただし必要なものだけを共有してください。アップロードはパブリック Web ルートの外部に保存され、許可されたスタッフのみが閲覧できます。図面が機密である場合は、アップロードする前に NDA をリクエストしてください。ファイルの種類とサイズはチェックされますが、この展開ではウイルス対策スキャンは要求されません。

リードタイムはどれくらいですか?

確認された製造または配送リードタイムは公表されていません。 SKU、仕上げ、数量、梱包、配送ルートによって異なります。チームは仕様と目的地を検討した後、タイミングを確認します。
